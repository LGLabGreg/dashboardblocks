Dashboardblocks is a collection of high-quality dashboard components built on top of [shadcn/ui](https://ui.shadcn.com). Install only what you need, customize everything, and own your code.

## Why Dashboardblocks?

Most dashboard UI libraries force you to choose between generic components that don't fit your needs or monolithic templates you can't easily customize. Dashboardblocks takes a different approach:

- **Individual installation** — Install components one at a time via the shadcn CLI. No bloated dependencies.
- **Composable primitives** — Each component is built from small, reusable pieces you can mix and match.
- **Dashboard-focused** — Purpose-built for analytics, admin panels, and data-heavy interfaces.
- **Own your code** — Components are copied into your project. Customize freely without fighting abstractions.

More blocks are on the way, including dashboard headers, stat groups, heatmaps and goal trackers.

## Dashboards

Full dashboards composed from the blocks, with header filters that scope every block below them.

Each dashboard is a single component you can install and adapt. Its header controls one query: the date range, comparison and filters. Every block below re-renders from that query, so the numbers always agree. While new data loads, the blocks stay in place, dimmed, instead of flashing skeletons.

The data comes from one function in each file (`buildStoreData` and `buildSaasData`). Replace it with your own queries; the blocks only need their props.

### Store

Revenue, orders, average order value and conversion, with revenue over time, revenue by channel, top products and a checkout funnel. Filter by date range and region, and compare with the previous period.

[Open the store dashboard](/docs/examples/store)

```bash
npx shadcn@latest add https://dashboardblocks.com/r/dashboard-01.json
```

### SaaS

MRR, active accounts, churn and NPS as metric tabs, an activity heatmap, accounts by region and live service status. Filter by date range and plan.

[Open the SaaS dashboard](/docs/examples/saas)

```bash
npx shadcn@latest add https://dashboardblocks.com/r/dashboard-02.json
```
