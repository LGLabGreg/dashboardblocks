---
title: Examples
description: Full dashboards composed from the blocks, with header filters that scope every block below them.
---

Each example is a single component you can install and adapt. Its header controls one query: the date range, comparison and filters. Every block below re-renders from that query, so the numbers always agree. While new data loads, the blocks stay in place, dimmed, instead of flashing skeletons.

The data comes from one function in each file (`buildStoreData` and `buildSaasData`). Replace it with your own queries; the blocks only need their props.

## Store

Revenue, orders, average order value and conversion, with revenue over time, revenue by channel, top products and a checkout funnel. Filter by date range and region, and compare with the previous period.

[Open the store dashboard](/examples/store)

```bash
npx shadcn@latest add https://dashboardblocks.com/r/dashboard-01.json
```

## SaaS

MRR, active accounts, churn and NPS as metric tabs, an activity heatmap, accounts by region and live service status. Filter by date range and plan.

[Open the SaaS dashboard](/examples/saas)

```bash
npx shadcn@latest add https://dashboardblocks.com/r/dashboard-02.json
```
