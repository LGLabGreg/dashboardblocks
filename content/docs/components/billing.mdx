MRR movement always adds up: starting MRR plus new and expansion, minus contraction and churn, gives ending MRR. Movements are small next to the totals, so the waterfall's axis starts below the lowest running total, the total bars show a break, and the axis says where it starts. Amounts go through one currency formatter, and dates are formatted in UTC so they render the same on the server and in the browser. Increases, decreases and invoice statuses each come with a sign, an icon or a label, so colour never carries them alone.
