Built on shadcn's [Command](https://ui.shadcn.com/docs/components/command). Pass groups of items, and the menu filters them as the user types, matching labels, descriptions and keywords. To search your API instead, pass `query` and `onQueryChange`, and the menu shows the groups you give it. Items either go to an `href`, through `onNavigate` for your router, or run `onSelect`.

### Pages and Actions

Jump to a page or run an action, with shortcuts shown beside actions. It opens on <kbd>⌘K</kbd> by default. This preview uses <kbd>⌘/</kbd>, because <kbd>⌘K</kbd> opens this site's search.

### Record Search

Recently viewed records before you type, then customers and orders fetched as you type, with a searching state. Try "jonas" or "1042".
