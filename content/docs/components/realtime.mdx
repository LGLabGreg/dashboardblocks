Realtime blocks show data that keeps changing. Each block takes its first values as props, so it renders the same on the server and in the browser, then updates from state. Set `simulate` to see it move with made-up data, or replace the interval in the block with your own feed, such as a WebSocket or polling. Numbers count to each new value, and the pulse and counting stop for reduced motion. Updates aren't announced to screen readers, which would be noisy every second.
