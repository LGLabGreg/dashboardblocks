## Installation

```bash tab="pnpm"
pnpm dlx shadcn@latest add https://dashboardblocks.com/r/kpi.json
```

```bash tab="npm"
npx shadcn@latest add https://dashboardblocks.com/r/kpi.json
```

```bash tab="yarn"
yarn dlx shadcn@latest add https://dashboardblocks.com/r/kpi.json
```

```bash tab="bun"
bunx --bun  shadcn@latest add https://dashboardblocks.com/r/kpi.json
```
