---
title: KPI
description: KPI cards with the change on the last period, progress to a target, and bar, line and area charts.
---

A KPI card puts one headline number first, with what it means next to it: the change on the previous period, the target it's working towards or the shape of the week behind it. Changes come from the value and the previous value, in percent or in percentage points for rates, and keep their arrow and sign so colour never carries them alone. Use `goodDirection` for metrics like churn, where a drop is good. Values count up once in view, and screen readers get the final value. Numbers use named formats in `en-US`, so the server and the browser render the same, and every chart has a text alternative.
