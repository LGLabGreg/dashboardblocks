Distributions show the shape of a metric, not just its average: where most values sit, how far the tail reaches and whether a few large values pull the mean up. Blocks take binned counts, such as histogram buckets from a metrics backend, a summary of percentiles or raw values. Percentiles from bins assume values are spread evenly within each bin, so they are estimates. Every chart comes with a table of the same values for screen readers.
