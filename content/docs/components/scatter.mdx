Scatter blocks plot two measures against each other, one dot per item. Series keep their colour in a fixed order, and every point has a tooltip and a row in the table read by screen readers. A correlation is a least-squares line with Pearson's r, described in words, which says how closely two measures move together, not that one causes the other.
