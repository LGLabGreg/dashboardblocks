Every step is done, in progress, to do or skipped, and each state has its own marker shape and a text label, so colour never carries it alone. Skipped steps are left out of the total, so skipping an optional step doesn't hold progress back. Use these for steps people tick off; for numeric targets, use Goals.

### Onboarding

Setup steps with a progress ring. Each step expands to show what it involves, with the action on the current step and a skip button on optional ones.
