Spend blocks compare what's gone out with what was planned. Pace assumes the budget is spent evenly over the period, so the projection is spend so far divided by the share of the period gone. A status says whether that lands under, on or over budget, with an icon and a label as well as a colour. Pass fixed dates, so the blocks render the same on the server and in the browser.
