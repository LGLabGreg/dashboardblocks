Choice cards are native radio buttons and checkboxes, so Tab reaches each group, the arrow keys move between options and they work in any form. When a step changes, focus moves to its title, so keyboard and screen reader users start from the top. The wizard's fields use `useSimpleForm` from [Forms](/docs/components/forms), and setup progress uses the [Checklist](/docs/components/checklist) primitives. For a getting-started checklist inside a dashboard, see [Checklist: Onboarding](/docs/components/checklist#onboarding). Links are plain `<a>` elements. For client-side navigation, pass your router's link to `LinkProvider`. See [Routers](/docs/compatibility#routers). The wizard's Sign out stays a plain `<a>`, since signing out usually needs a full request.

### Setup Wizard

Name the workspace and pick its URL, say what it's for, then invite the team. Each step checks its own fields, and the URL is checked with the server before moving on. Try `acme` to see a taken URL. Paste a list of addresses into an email field to fill a row for each.
