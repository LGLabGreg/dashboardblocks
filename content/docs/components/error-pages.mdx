Error pages say what happened in plain words, whose fault it was, and what to do next, so nobody is left on a dead end. Each one is a full page built on `ErrorPageLayout`: your brand at the top, a centred message, then actions. Leave out `brand` to use one inside an [app shell](/docs/components/app-shell). Pass `focusOnMount` when the page is a route, so focus moves to the title and screen readers announce the error after a client-side navigation. Times are shown in UTC, and anything that waits on the server shows that it's working and says when it fails again.
