Deployment blocks show what shipped, where it's running and how healthy the pipeline is. Statuses (ready, failed, running, queued and rolled back) each have an icon and a label, and the running spinner stops for reduced motion. DORA metrics are rated against the widely used elite, high, medium and low bands; bands differ between reports, so adjust `getDoraLevels` to yours. Pass fixed dates, so the blocks render the same on the server and in the browser.
