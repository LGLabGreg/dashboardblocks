What's coming up, the forward-looking counterpart to the activity feed. Every date helper takes a fixed `now` and a time zone (UTC unless you pass one), so days, times and countdowns render the same on the server and in the browser. Each event's colour comes with its calendar name, and urgency comes with an icon and a label, so colour never carries meaning alone.

Upcoming events grouped by day, as Today, Tomorrow and then weekdays, with the event in progress marked.
