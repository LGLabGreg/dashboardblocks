title: Usage Meter
description: Usage meters for quotas, storage, metered billing, prepaid credits and plan limits, with projections and upgrade prompts.
---

Usage meters show how much of a limit is used and what happens next. Usage is within limit, nearing it from 80%, critical from 95% and over past 100%, and each status has an icon and a label, so colour never carries it alone. Projections take the average daily rate so far to the end of the period, drawn as a striped segment on the bar. When usage or a projection goes past the limit, the bar extends and the limit shows as a tick. Pass fixed dates, so the blocks render the same on the server and in the browser.

### Quota

An API quota with its status, when it resets and the usage it's on pace for, with the date it would hit the limit.
