The sidebar layouts use shadcn's [Sidebar](https://ui.shadcn.com/docs/components/sidebar), so collapsing, the mobile sheet, <kbd>⌘B</kbd> and theming all work as documented there. These blocks add what goes in it. Navigation comes from data and marks the active link from the current path.

Links are plain `<a>` elements. For client-side navigation, render your router's link instead. With React Aria, wrap your app in its `RouterProvider`.

### Sidebar

A workspace switcher, navigation sections with count badges and a user menu. The top bar holds breadcrumbs, search on <kbd>⌘K</kbd> and notifications.

### Icon Sidebar

Collapses to icons with tooltips, using the trigger, the rail or <kbd>⌘B</kbd>. Sections with child links open when one of them is the current page. Help and settings are pinned to the bottom.

<ComponentPreview name='app-shell-02' layout='page' />

### Inset

The page sits in a card beside the sidebar. Plan usage with an upgrade link sits above the user menu.

<ComponentPreview name='app-shell-03' layout='page' />

### Top Navigation

No sidebar. Page links sit under the top bar and scroll sideways on small screens. The user menu is an avatar.
