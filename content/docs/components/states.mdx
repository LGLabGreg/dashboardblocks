---
title: States
description: Loading, refreshing, empty and error states that keep the block's layout.
---

Each block takes a `load` function that returns a promise, and the `useBlockData` hook tracks its status. Use a skeleton only for the first load. When data is already on screen, keep it in place while it refreshes, dimmed, so the layout doesn't jump.

### Skeleton

Placeholders sized to match the loaded stats, so nothing shifts when the data arrives. Select Reload to see them again.
