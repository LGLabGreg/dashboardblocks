Timelines place work on a calendar. Dates are handled in UTC, so pass fixed dates and a fixed `now`, and the blocks render the same on the server and in the browser. Statuses (done, in progress, planned and at risk) each have an icon and a label, so colour never carries them alone. Wide timelines scroll sideways in narrow cards, with the labels kept in view.

### Roadmap

Projects grouped by team, each a bar from start to end filled to its progress, with a today line. Hover a bar for its dates.
