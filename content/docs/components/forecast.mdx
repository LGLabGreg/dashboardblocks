Forecasts are a straight-line fit through the actuals, with a prediction interval that widens the further ahead it looks. It's a normal approximation, good enough to show uncertainty on a dashboard but not to plan on. Actuals are solid and forecasts dashed in the same hue, with a shaded range and a label, so a forecast never relies on colour to stand apart. Pass fixed dates, so the blocks render the same on the server and in the browser.
